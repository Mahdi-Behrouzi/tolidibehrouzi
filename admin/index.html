فرم ثبت نظر (نمونه‌ی زنده)

هر نظری که اینجا ثبت شود، بلافاصله در بخش «مدیریت نظرات» به‌صورت در-انتظار ظاهر می‌شود.

اتصال زنده به سایت

این پنل مستقیماً به همان bin روی jsonbin.io وصل است که فایل comments.js روی سایت اصلی به آن می‌نویسد. یعنی هر نظری که کاربر واقعی توی سایتت ثبت کنه، همینجا در «مدیریت نظرات» به‌صورت خودکار در-انتظار ظاهر می‌شه؛ فرمِ بالا هم فقط برای تست سریع همین اتصال است، بدون نیاز به تغییر دادن سایت اصلی.

نکته‌ی امنیتی

کلیدی که برای این اتصال استفاده شده، یک Master Key کامل jsonbin.io است و همین الان داخل کد این پنل و همچنین کد comments.js سایتت به‌صورت خام قرار داره؛ یعنی هر کسی که کد سایتت رو ببینه می‌تونه همین‌طوری کل نظرات رو تغییر بده یا پاک کنه. اگه jsonbin.io کلید محدود (فقط-نوشتن) داره، بهتره از اون به‌جای Master Key استفاده کنی؛ در غیر این صورت پیشنهاد می‌شه این مسیر رو از پشت یک سرور واسط (مثل یک Cloudflare Worker کوچک) رد کنی تا کلید فقط سمت سرور بمونه.
